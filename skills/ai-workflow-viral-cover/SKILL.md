# AI Workflow Viral Cover

## 定位

生成一类适合内容传播的「高智感爆款封面」。核心气质：**高智感、强结果感、爆款封面冲击力、商业复盘、AI 工作流、系统协作、效率提升**。

核心目标：让读者在 **1 秒内看到结果**，在 **3 秒内理解主题**，在 **5 秒内相信这篇内容值得点开**。

---

## 核心视觉公式

爆款封面 = **大数字结果 + 强冲突标题 + 高对比色彩 + AI 隐喻图形 + 数据证明 + 行动金句**

拆解为六个视觉锤：

1. **第一视觉锤**：巨大数字 — 例如 15倍、7天、22个项目
2. **第二视觉锤**：结果词 — 效率、复盘、工作流、系统、Agent、Skill
3. **第三视觉锤**：红黑金高对比配色
4. **第四视觉锤**：AI 大脑 / 神经网络 / 工作流节点图形隐喻
5. **第五视觉锤**：底部数据条增强可信度
6. **第六视觉锤**：一句判断型金句完成价值表达

### 色彩逻辑

- **黑色**（60-70%）：制造深度、理性、高智感
- **白色**（15-20%）：保证标题识别度
- **红色**（10-15%）：制造冲击、紧迫感，仅用于关键数字、关键词、线条光效、强调符号
- **金色**（5-10%）：制造价值感，仅用于"倍"字、价值词、数据模块、品牌名、底部标签

## 字体规则

- **风格**：粗黑体 / 几何黑体 / 压缩黑体 / 海报黑体 / 现代无衬线
- **禁止**：宋体正文风、手写体、圆体、儿童字体、过细字体、过度艺术字体
- **字号比例**：一级标题 100% → 二级 65-75% → 三级 35-45% → 数据模块 25-35% → 底部标签 18-24%
- **标题排版**：必须拆行，不要把所有信息排成一行。正确示例"15倍→效率→7天·22个项目→我和 AI 的真实复盘"

## 文案规则

下列数字仅为排版示例，使用时必须替换为用户已确认的真实数据；没有数据就使用文字主题，不编造结果。

### 主标题（结果感）
示例：`15倍效率` / `7天，22个项目` / `AI 协作复盘` / `越做越快的秘密`

### 副标题（解释主题）
示例：`我和 AI 的真实复盘` / `从零散工具到系统协作`

### 金句（判断型）
默认：**"不是 AI 替你工作，而是你和 AI 一起越做越快"**
其他可选：`效率不是来自工具，而是来自协作系统` / `真正的提效，是人和 AI 之间的默契越来越深`

### 数据模块（3-4个）
示例：`1.5亿 Token | 59+ Skills | 7 大类别 | 20+ 会话语境`

## 信息密度控制

- 主标题：1 个
- 副标题：1 个
- 数据模块：3-4 个
- 流程节点：3-4 个
- 底部金句：1 句
- 底部标签：4-8 个
- **总中文字符不超过 80 个**

## 生成 Prompt 模板

当用户要求生成封面图时，使用 ImageGen 工具，构建以下 prompt。

### 生图工具适配

使用当前环境实际提供的生图工具，按其支持的参数传入提示词、比例和画质；不要假设所有工具都有相同的参数。没有可用生图工具时，交付完整提示词和版式说明，并明确尚未生成图片。

比例优先传入工具支持的宽高比；使用像素尺寸时须保持比例，例如 3:4 为 768×1024。若工具不支持精确尺寸，说明实际输出尺寸及需要的后续裁切。

标题、品牌署名和数据使用用户提供的真实素材。未提供数据时省略数据模块，不把示例数字当作成果。保留工具或平台要求的来源标识。

### Prompt 模板

```
生成一张适合{平台}传播的高智感爆款封面图。

主题：{主题}
核心信息：{核心数据}
主标题：{主标题}
副标题：{副标题}
底部金句：{金句}
画面比例：{比例}

视觉风格：高对比、高智感、爆款封面、AI 工作流、商业复盘、未来科技感、系统协作感。
整体使用黑红金白配色，背景为深黑/石墨黑，加入暗红渐变、金色点缀、白色大标题。
画面必须有强视觉冲击，但不能廉价和杂乱。

版式要求：
- 顶部放品牌署名
- 左侧或中上部放超大标题，数字必须最大
- 中部放副标题
- 右侧放 AI 大脑/神经网络/工作流节点图
- 底部放数据模块和传播金句
- 底部放关键词标签

字体要求：厚重、锋利、现代中文黑体风格，主标题极大有力量。

配色要求：背景深黑/石墨黑，主标题白色+红色，关键词红色或金色，数据数字红色，价值词金色，辅助文字浅灰，线条红色微光/金色细线。

图形要求：细微科技线条、红色发光轨迹、神经网络节点、数据曲线、流程节点。

禁止：小清新、普通蓝色科技风、植物、卡通、人物照片、低级赛博朋克、过度装饰、水印。
```

## 平台适配

- **小红书封面（1:1 或 3:4）**：主标题最大、数字冲击优先、字数精简、强对比
- **公众号封面（16:9 或 21:9）**：横向空间更大、增加右侧 AI 工作流图、数据模块横排、整体更克制
- **朋友圈海报（1:1 或 3:4）**：金句更重要、减少数据模块、不要像广告、像真实复盘
