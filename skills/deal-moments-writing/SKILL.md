# 成交型朋友圈写作

把真实素材写成适合个人朋友圈发布的文案。目标不是硬广，而是让别人更理解你、信任你、愿意咨询你。

## 适用场景

- 用户说「帮我写朋友圈」「写一条成交型朋友圈」「把这个案例写成朋友圈」。
- 用户提供产品、课程、服务、客户反馈、聊天记录、项目复盘、个人经历。
- 用户需要连续几条朋友圈来铺垫信任、解释价值、引导咨询。
- 用户想把文章或笔记改短，变成手机里能自然发布的表达。

## 核心原则

成交型朋友圈必须先像人话，再像文案。

- **真实**：用具体细节、场景、过程，不写虚假客户和夸张结果。
- **自然**：像一个人在讲自己的观察，不像公众号标题党。
- **有价值**：读者看完得到一个判断、方法、提醒或情绪共鸣。
- **有指向**：结尾可以轻轻引导咨询、报名、领取资料、私聊。
- **有克制**：不把每一条都写成强销售。

## 输入要求

尽量提取以下信息：

- 这条朋友圈想达成什么：建立信任、解释产品、展示案例、促成咨询、日常种草。
- 面向谁：客户、学员、同行、潜在合作方、老朋友。
- 核心素材：经历、案例、反馈、截图、笔记、观点。
- 是否能公开：客户名、金额、截图、公司名、隐私信息。
- 语气偏好：克制、温暖、犀利、复盘感、生活化、专业感。

如果用户没有提供明确目标，默认写成「建立信任 + 轻引导咨询」。

## 文案类型

根据素材选择一种，不要混成四不像：

- **经历复盘型**：我遇到了什么、怎么判断、学到了什么。
- **客户案例型**：客户原来怎样、卡在哪里、怎么变化。
- **观点教育型**：纠正一个误区，给出一个判断标准。
- **产品解释型**：不用参数解释产品，而是解释它解决什么问题。
- **日常信任型**：用生活化观察呈现长期价值观。
- **连续铺垫型**：3-5 条朋友圈，从问题、案例、方法、反馈到行动。

## 执行流程

1. **判断成交位置**
   - 这条文案处在成交链路的哪一步：看见你、信任你、理解产品、产生咨询、临门一脚。

2. **提炼主线**
   - 用一句话确定这条朋友圈要让读者相信什么。
   - 一条朋友圈只打一个点。

3. **重组素材**
   - 开头先给场景、冲突、反常识或真实细节。
   - 中间讲过程、判断、案例或方法。
   - 结尾给轻行动，不强迫、不喊口号。

4. **写 2-3 个版本**
   - 短版：100-200 字，适合日常发。
   - 标准版：250-500 字，适合讲清楚一件事。
   - 强转化版：在不夸张的前提下增加行动引导。

5. **安全检查**
   - 删除隐私信息、内部链接、敏感截图内容。
   - 删除无法验证的收益承诺。
   - 删除过度营销词，如「唯一」「稳赚」「闭眼买」「保证」。

## 输出格式

```text
【适合发布的版本】
...

【更短一点】
...

【更有成交指向】
...

【发布建议】
- 适合时间：
- 是否配图：
- 评论区可补一句：
- 私聊承接话术：
```

如果用户要求连续朋友圈，输出：

```text
【连续 5 条朋友圈】
Day 1：制造看见
Day 2：解释问题
Day 3：展示案例
Day 4：给出方法
Day 5：轻转化
```

## 边界

- 不编造客户案例、付款截图、转化数据。
- 不把朋友圈写成正式文章、小红书笔记或广告海报。
- 不替用户承诺疗效、收益、确定性结果。
- 如果素材明显不适合成交，先改成信任型或观点型。

## 示例提示词

- 「把这个客户反馈写成一条自然的朋友圈。」
- 「我今天做了一个 AI 课程直播，帮我写成交型复盘朋友圈。」
- 「围绕这个产品，帮我写 5 条连续朋友圈。」
- 「这段话太像广告了，帮我改得像真实朋友圈。」
